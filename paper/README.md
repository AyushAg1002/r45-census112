# Manuscript build

Install Tectonic 0.17.0. From the `paper/` directory in the source archive,
build the preprint with:

```sh
tectonic -X compile main.tex --keep-logs
```

In the arXiv-source archive, `main.tex` is at the archive root; run the same
command there.

The approved author is Ayush Agarwal, Independent Researcher, Bangalore,
India. The public repository is
<https://github.com/AyushAg1002/r45-census112>. The archival release is
<https://doi.org/10.5281/zenodo.22057247>. The manuscript and documentation
are CC BY 4.0, original code is MIT-licensed, and the derived catalogue and
original manifests are CC0 1.0.
The mathematical text intentionally states the catalogue dependencies and
does not claim a complete census of the saturated residue or a new upper
bound for `R(5,5)`.
